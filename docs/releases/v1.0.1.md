# Yamashin WP Migration v1.0.1

既存の移行・検証・ロールバック機能を保ったまま、ブランド資産、互換性検証、反復E2E試験の信頼性を更新するメンテナンスリリースです。

## 変更点

- 山真Appsのブランド仕様に合わせたロゴ、配布資産、WordPress管理画面ヘッダー
- PHP 8.5の継続検証と互換性警告の解消
- WordPressの最小互換情報とGitHub Actionsランタイムの更新
- staging／productionの反復試験でCompose内URLを正しく照合する修正
- タグ、プラグイン、WordPress stable tag、MCP packageの版番号不一致をリリース前に拒否する検証

## アップグレード

WordPress管理画面から旧版を停止・削除して本リリースZIPをアップロードするか、同じプラグインディレクトリへ上書きしてください。既存設定と移行履歴は保持されます。実運用前にはstagingでドライランとロールバック可能性を確認してください。
