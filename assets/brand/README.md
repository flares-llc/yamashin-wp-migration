# Yamashin WP Migration brand assets

The mark uses the Yamashin Apps `231 × 257` master grid. Its filled source,
outlined target, directional arrow and Y-shaped route represent a deliberate
one-way migration between two WordPress environments.

- `mark`: favicon, compact avatar and app-list use
- `vertical`: centered product and repository surfaces
- `horizontal`: compact application headers
- `ogp`: social previews
- `*-white`: opaque white field
- `*-transparent`: alpha-transparent field

`yamashin-wp-migration-mark-fragment.svg` is the geometry source. All other
SVG and PNG files are generated from it with the Yamashin Apps brand identity
generator. The generated SVG wordmark consists only of fixed paths; it has no
font or text dependency.
